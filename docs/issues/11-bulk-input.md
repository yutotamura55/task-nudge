# Issue #11: タスクの一括入力

対象は、複数行のテキストを貼り付けて各行を独立したタスクとして登録する操作。
単件登録と編集は従来の画面を使う。

## 入力と確定

- 一覧の「まとめて追加」から一括入力画面を開く。1 行を 1 タスクとして扱い、各行の前後の空白を除く。空行は読み飛ばし、同名の行は別タスクとして残す。
- 繰り返し日数は全件共通。初期値は 1 日、1〜365 日の整数。タスク名は各 1〜100 文字、一度に 1〜100 件。
- 無効な行や日数があれば保存せず、入力欄に理由を表示する。保存時には全件を 1 回の DB トランザクションで確定する。途中の INSERT が失敗しても一部の行を残さない。
- 保存結果は一括入力画面の session が所有する。確定後の再タップでは重複登録しない。画面を離れた後に届いた結果は新しい画面を遷移させない。
- 確定後は一覧へ戻り、DB の観測は別に続ける。観測失敗時は既存の再読み込み操作で確認する。

## 検証

`BulkTaskInputTest` は空行、空白、同名、件数上限、無効な行を確認する。
`ReminderEngineTest` は一括確定、1 回の再評価予約、INSERT 途中失敗時の rollback を確認する。
`TaskViewModelTest` は入力エラー、連打抑止、旧 session の結果隔離を確認する。
`TaskScreensTest` は貼り付けから保存までの画面操作を確認する。
