# Issue #13: 一括入力欄の横スクロール

一括入力の長いタスク名は、画面幅で折り返さず、入力欄を横にスクロールして確認・編集する。テキストに含まれる改行は残し、改行ごとに別タスクとして保存する。保存ルールと DB 処理は [Issue #11](11-bulk-input.md) のまま。

Compose Material 3 の複数行 `OutlinedTextField` は画面幅で折り返すため、この欄だけ Android の `EditText` を `AndroidView` で表示する。`TYPE_TEXT_FLAG_MULTI_LINE` で改行を受け取り、`setHorizontallyScrolling(true)` で自動折り返しを止める。入力値は画面の保存可能な状態と同期し、実際のテキストが変わらない再描画では `setText` を呼ばず、入力中のカーソルと変換状態を保つ。入力欄内で始まるスワイプは入力欄で処理し、横と縦の両方向にスクロールできるようにする。

端末テストでは、長い 1 行と改行後の 1 行が画面上で 2 行のまま表示され、横スワイプで長い行の末尾へ移動し、保存後は 2 件となることを確認する。20 行入力時の縦スクロールとテキスト選択、IME 接続を通した日本語の変換中テキストと確定も確認する。実際の日本語キーボード操作までは自動化していない。貼り付け操作はクリップボードを変更するため、隔離した CI エミュレーターだけで実行する。
