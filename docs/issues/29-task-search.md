# Issue #29: 登録済みタスクの検索

## 変更範囲

一覧の「検索」からタスク名を部分一致で絞り込む。入力の前後の空白と英字の大文字小文字は検索結果に影響しない。停止中のタスクは一覧の既存の表示切替に従う。検索語は詳細画面から戻った後と画面再作成後も保持する。検索欄を閉じると絞り込みを解除する。保存データと通知処理は変更しない。

## 検証とレビュー

- 単体テストで部分一致、英字の大文字小文字、空白、停止中表示との組み合わせを確認する。
- API 35 エミュレーターの画面テストで検索、結果件数、結果なし、解除、詳細からの復帰を確認する。
- ローカル環境には Android SDK と JDK 17 がなく、`scripts/check.sh` と接続端末テストは実行できない。PR の Android CI で単体テスト、lint、APK ビルド、エミュレーター上の画面テストを確認する。
- 独立レビュー: Codex の別コンテキストのサブエージェント（モデル識別子は取得不可）が `origin/main` との差分を読み取り専用で確認。重大な指摘なし。検索結果の読み上げ通知を提案され、結果件数と polite live region を追加。追加差分の再レビューでも指摘なし。
- 別モデルの CLI レビューは、Gemini 3.8 Flash High を指定した `agy` の初回実行が読み取り権限不足で終了し、再実行が応答を完了しなかったため成立しなかった。Copilot CLI では指定した Claude モデルが利用不可だったため、上記の別コンテキストでのレビューに切り替えた。
